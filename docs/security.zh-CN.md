# 安全配置

## 请求处理链

```
入站（受信代理开启时先还原真实客户端 IP） → 信任名单(阶段 0) → GeoIP 标签 → IP 预检(多策略合并) → 压缩(encode) → 请求体限制 → 限流 → WAF(CRS+自定义) → 反向代理
```

任一阶段拦截即刻返回配置的状态码与拦截页。

受信代理（CDN/前置代理回源）启用时，仅受信网段发来的代理头会被采信，还原后的真实客户端 IP 参与名单/地域/限流/事件判定；未启用或来源不在受信网段时一律按 TCP 源地址判定（fail-closed）。配置方式见[部署指南 · 受信代理](deployment.zh-CN.md#受信代理cdn-真实-ip-还原)。

## 安全策略

安全策略是独立实体，绑定到 HTTP 规则（一策略绑多规则，一规则最多绑 8 策略）。

**策略类型（实体单职化，2026-09-20）**：策略按管辖阶段单职化为四类——阶段 0 · 信任名单 / 阶段 1 · IP 访问控制（黑白名单+地域+威胁库引用）/ 阶段 2 · 限流 / 阶段 3 · WAF；存量多阶段混合策略保留为「混合（兼容）」，可在策略页「更新迁移」拆分为单职子策略。**触发阶段四分类（事件页筛选与触发列）**：信任名单 / IP 访问控制（黑白名单+地域+威胁库合并口径）/ WAF（CRS 与自定义合并，具体规则在触发详情弹框内展示）/ 请求体异常。**攻击类型分布（安全总览）**：默认按阶段五桶展示（与触发阶段口径一致），取消「按阶段展示」勾选切换具体分类（SQL注入/XSS/扫描探测/自定义规则等）。

| 设置 | 选项 |
|---|---|
| WAF 模式 | 关闭（全关）/ 仅自定义（CRS 不生效）/ 检测（仅记录）/ 拦截（达阈值 403） |
|异常阈值|1/3/5/10/15/20（写侧枚举校验；导入通道的历史 0 值行在下次重启时由启动归一回填 5（sync_security=1 从节点除外，以主节点快照为准）。发射端直读库值、无写死兜底：残留无效值（≤0，带外直写才会出现）渲染时显性报错（fail-visible），配置保存被拒绝 |
| CRS 规则组 | 按攻击类型组加载/排除 |
| 自定义规则 | URI/args/headers/body/UA 多条件链式匹配 |
| IP 控制 | 白名单 / 黑名单 / 信任名单，CIDR，可引用 IP 列表 |
| 地域控制 | 拦截所选区域 / 仅允许所选区域 |
| 限流 | 按 IP 速率 + 突发 |
| 拦截响应 | 自定义 HTML + 状态码（离散值：400/401/403/404/503；限流拦截恒为 429，自动语义不在可选集） |

多策略绑定时，deny 侧 IP 控制合并为链首预检——被拒 IP 在任何规则评估前即被中断。**事件归因语义**：一条事件被多个绑定策略覆盖（多策略 CRS 重叠）时，按绑定顺序取第一条（policy_id ASC）记为归属策略——实际执行拦截的引擎实例在审计数据中不可恢复，归因是摄取期记账口径（安全事件页与策略 24h 计数同口径），不构成 forensic 判定。

**信任名单语义**：阶段 0 信任策略的「保留检测记录」开关决定处理方式：**关闭（默认，`trust_detection=0`）**时，命中任一绑定直通策略信任名单的 IP 直接转发上游，跳过 IP 预检、压缩、请求体限额、限流与 WAF 等后续安全流程，不产生安全事件；**开启（`trust_detection=1`）**时，信任 IP 在预检与该规则绑定的每个策略引擎中均按 DetectionOnly 仅记录、不拦截，限流仍然生效。阶段 0 信任按规则绑定生效；其他策略可引用同一信任地址列表。

**拦截页归因（按触发方，阶段化模型）**：规则配了阶段拦截页（阶段 1=IP 访问控制/地域拦截、阶段 3=WAF）时，对应阶段的全部拦截返回该规则的阶段页与状态码（引擎内以合成中断码 481/482 归因）；未配阶段页时按触发策略归因——每个绑定策略在引擎内分配独立合成中断码（483 起），返回该策略配置的拦截页与状态码；策略也未配页时回落默认 403（兜底归因边界）。多策略绑定无需再为归因统一拦截页配置。

## 安全事件

自动采集 WAF 拦截、IP ACL 拒绝、GeoIP 拦截。含趋势图、TOP 攻击类型/来源 IP（带地理位置）。**IP 处置入口**：点击事件列表中的 IP 地址打开快捷弹框——按策略卡单击完成拦截/放行/信任（自动解析既有列表，无同侧列表时自动创建「{策略名}-黑名单/-白名单/-信任」并关联加入）；触发阶段链接打开触发详情弹框（纯信息展示，零操作）。审计日志按大小轮转（默认 10MB × 5 份）。

## 规则集更新

CRS 和 IP2Region 支持手动/自动更新（失败自动回滚）。每次成功更新持久化规则树快照到数据卷，容器重建后自动恢复。


### 自动封禁

面板提供基于阈值计数的自动封禁（默认观察模式，不直接封禁）：

- **开关**：安全事件页「自动封禁」状态卡；关闭后不再新增封禁条目，已有名单保留。
- **判定**：在配置时间窗内，同一来源 IP 符合统计口径的安全事件达到阈值后进入自动封禁名单。统计口径三选一：全部事件（默认）/ 仅拦截 / 仅检测；另可配置封禁时长（10 分钟至永久）。
- **观察模式**：默认开启，只记录候选与状态，不写入执行名单；确认误封率可接受后关闭观察模式。
- **生效条件**：自动封禁名单必须被安全策略的「IP 访问控制」以黑名单（deny）模式引用才生效；未被引用时名单只可见、不拦截。
- **与威胁情报库的区别**：威胁情报库是外部只读源；自动封禁是本地行为计数产生的系统名单，二者都在 IP 地址列表中展示，但数据来源与更新任务不同。

### 威胁情报库

内置三个只读情报源（USTC 黑 IP / FireHOL level1 / ET Compromised），条目聚合后写入 IP 地址列表中的三条 system 内置名单（只读，由更新任务维护）。

- **引用生效**：威胁名单无全局兜底规则——策略在「IP 访问控制」步骤引用对应内置名单才生效。内置名单仅允许黑名单（deny）模式引用；信任名单 / 白名单模式 / CRS 排除引用一律拒绝。
- **缺库降级**：CRS/IP2Region 库文件缺失时该节点安全链整体不渲染（IP 预检/ACL/限流/WAF/GeoIP 一并缺席），并告警提示补库（coraza Include 缺失文件会使整份配置被拒绝，负载均衡也会被拖死，故选择整体缺席）。威胁源单源失败仅影响该源，保留上次成功名单；引用空名单的策略其该名单拦截面为空。
- **更新排程**：任务级定时更新（星期多选 1=周一…7=周日 + HH:MM，默认每天 04:00，时区遵循基础设置的时区），自动更新总闸与逐源开关解耦；手动「立即更新」不受排程与开关影响。内容哈希未变化时跳过写入、不 bump 集群版本；内容有变化时名单文件直接热生效（约 1 秒内，无需重载面板或中断流量）；单源失败的重试在本次更新任务内完成；重试耗尽后不再按 1h→24h 额外退避，下一次自动运行时间仍按排程槽维护（空槽或过期槽推进到下一槽，已有未来槽不回拨）。
