## 遗留 / 备注
1. 预热设计：终结路径证书由 Caddy `tls internal` 内部 CA 异步签发，首连会失败，故预热对终结路径做最多 30s 的重试等待（本 run 签发约 1s 内完成）。透传路径一次即过。
2. 终结侧握手客户端校验用 insecure（InsecureSkipVerify=true）：终结证书由 Caddy 本地 CA 签发，不在 spike-local-ca 信任链内——与 T-1 C 断言同款做法。透传侧仍用 spike-local-ca **严格校验**。
3. 前两次运行失败原因（已修复，如实记录）：
   - run1：预热未重试 → `tls: internal error`（internal 证书未就绪）；
   - run2/run3：终结侧 ProbeTLS 传 insecure=false → `x509: certificate signed by unknown authority`。
4. 探测 ALPN offers 仅 http/1.1（与明文 HTTP/1.1 请求匹配；T-2 已验证 h2 协商路径本身无恙）。
